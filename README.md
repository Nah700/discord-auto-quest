# Discord Quest Spoofer [UPD:12/03/2026]

This JavaScript script allows you to **simulate progress in Discord Quests** by injecting code into the developer console of Discord (browser or desktop app). It supports quests like `WATCH_VIDEO`, `WATCH_VIDEO_ON_MOBILE`, `PLAY_ON_DESKTOP`, `STREAM_ON_DESKTOP`, and `PLAY_ACTIVITY`.

> ⚠️ **Use at your own risk. This script violates Discord's Terms of Service.**  
> Using this tool may result in account warnings, revoked rewards, or permanent bans.

---

## 🚀 Features

- ✅ Automatically detects an active, incomplete quest
- 🎥 Fakes video watching progress
- 🎮 Fakes running a desktop game/app
- 📺 Fakes streaming activity in a voice channel
- 🎤 Fakes activity in a voice channel

---

## 💻 How to Use

### Requirements

- A Discord account with at least one active quest (visible under the “Quests” tab)
- Access to developer tools (browser or Discord desktop app)

### Instructions

1. Open Discord in your browser or desktop app.
2. Open the **developer console**:
   - Chrome/Edge/Firefox: Press `F12` or Right-click → `Inspect` → Console tab
3. Paste the script code into the console.
4. Press **Enter** to execute.
5. Watch the console for progress updates or completion messages.

## 🛠 Supported Quest Types

| Task Name           | Description                                              |
|---------------------|----------------------------------------------------------|
| `WATCH_VIDEO`       | Fakes watching a promotional video                       |

| `STREAM_ON_DESKTOP` | Fakes streaming activity to a voice channel              |
